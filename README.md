# GameAutoPlay — 도깨비의세계 퀘스트 자동 진행

화면 캡처(mss) + 템플릿 매칭(OpenCV) + 키보드/마우스 입력(pydirectinput)만 쓰는 화면 인식 매크로.
게임 메모리·패킷은 건드리지 않는다. 현재 버전은 `version.py` 참고.

> ⚠️ 게임에 안티치트 로더(`ucldr_DKBI_GL_loader_x64.exe`)가 있다. 입력 매크로는 운영 정책 위반으로
> 계정 제재를 받을 수 있으니 사용 전 게임 약관을 확인할 것.

## 설치
```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 실행 (권장: 제어판)
`gui.bat` 더블클릭 → 관리자 권한 요청 → 제어판이 열리고 자동으로 시작한다.

v1.27부터 왼쪽 메뉴로 화면을 전환하고, 상단에서 시작·일시정지·정지를 조작한다.
앵벌·조작 감지 토글과 물약 구매·자리 회피는 그 아래에 있다. 글씨 크기와 기본 창 크기는 유지한다.
설정은 `Ctrl+K`로 검색하고 **설정 저장**으로 저장한다. 일반 설정은 다음 시작부터 적용된다.
창을 옮겨도 미저장 설정은 그대로 남으며, 시작하거나 완전히 종료할 때는 자동 저장한다.
`gui_settings.json`의 저장값이 `config.yaml`을 덮어쓴다. 수집과 보상 자동화는 사용자 요청으로 잠겨 있다.

관리자 브리지(`start_bridge.bat`)를 통한 재시작:
```powershell
.\.venv\Scripts\python.exe -c "from tools import ctl; ctl.send({'action':'kill'}); print(ctl.send({'action':'run','args':['gui.py','--autostart','--farm']}))"
```
`--autostart`는 자동 시작, `--farm`은 앵벌 시작, `--stay`는 현재 자리에서 앵벌 시작이다.

v1.28에서는 **도움말 → 환경 점검**으로 권한·설정·인식 파일·게임 창을 확인할 수 있다.
**진단 파일 저장**은 최근 로그와 비밀값을 제외한 설정을 로컬 ZIP으로 저장한다. 화면을 포함하거나 외부로 보내지 않는다.
설정의 **백업 / 복원**은 알림 비밀값을 제외하며, 복원한 설정은 검토 후 저장한다.
설정·프로필·실행 상태는 임시 파일에 먼저 쓰고 교체한다. 설정 파일이 손상되면 `.bak`에서 복구하고 화면에 알린다.
같은 게임의 봇은 제어판과 `run.py`에서 동시에 실행되지 않는다. 실행 오류는 정지 후에도 화면에 남는다.
예약은 저장한 값으로 동작한다. 일반 설정은 다음 시작, 예약 변경은 저장 후 반영된다.

필드 왼쪽 아래에 문파 도움의 주황색 악수 아이콘이 나타나면 입력 직전 상태를 다시 확인한 뒤 자동으로 한 번 누른다. 설정의 **문파 도움 자동 응답**에서 켜고 끌 수 있다.

| 탭 | 내용 |
|---|---|
| 대시보드 | 현재 상태(이동/전투/대화/사망…), 가동 시간, 사망·임무 전환·영기 수련 횟수 |
| 설정 | 기능 토글, 수치, 프로필(퀘스트용/앵벌용/밤샘용), 알림 토큰, 예약 실행, 버전 정보 |
| 통계 | 전투력 추이 그래프, 퀘스트별 사망 횟수, 최근 사망 기록 |
| 미리보기 | 게임 화면 썸네일 + 인식 결과 (테두리 색 = 상태) |
| 사냥터 | 사냥터 DB 보기/수정 (이름·몬스터 전투력·사용 여부) |
| 추천 | 스킬 / 선택 상자 / 무기 / 방어구 / 투력 공략집 / 사냥터 / 보물찾기. 선택 상자는 도술 조각 5개 우선순위, 보물찾기는 19개 지역 91개 지도와 수동 체크리스트를 제공 |
| 로그 | 실시간 로그 (경고만 보기 가능) |

창을 닫아도 실행 중이면 트레이로 숨어서 계속 돈다 (트레이 메뉴 → 완전히 종료).

명령줄 실행: `.\.venv\Scripts\python.exe run.py` (퀘스트) / `run.py --farm` 또는 `farm.bat` (사냥터 전용) / `--dry-run` (클릭 없이 로그만)

## 동작 요약
- **상태 머신** (bot2/brain.py): 사망 > 대화 > 다른 화면 > 전투 > 이동 > 정지 순으로 판단해 한 가지 동작만 한다.
- **퀘스트**: 오래 멈춰 있으면 오른쪽 트래커의 메인 퀘스트 클릭 → 진행이 없으면 트래커 OCR 스캔 → 임무 화면(J)에서 본편→서사→일일→주간.
- **대화**: '넘기기' 버튼이 보이면 클릭.
- **사망**: 무료 복귀 버튼만 누른다(유료 즉시 부활은 절대 누르지 않음).
  - 죽은 퀘스트는 30분 중단, 같은 퀘스트에서 또 죽으면 60분·120분… (최대 4시간)
  - **전투력 게이트**: 한 퀘스트에서 2번 죽으면 전투력이 3% 오를 때까지 재도전하지 않는다.
  - 다른 퀘스트가 없으면 전투력에 맞는 안전 사냥터로 걸어가 자동 사냥.
  - 기록: `logs/deaths.jsonl`, 화면: `screenshots/death_*.png`
- **사냥터 모드** (bot2/farm.py): 사냥 허용 범위는 내 전투력×1.5 이하. 길라잡이 순간이동 후보는 내 전투력 이하로 제한한다.
  기본은 길라잡이(F5) 추천 사냥터의 **무료 순간이동**(37K~335K 사다리), `farm.travel: map`이면 세계지도 걸어가기(`farm_spots.json`).
  15분마다 재평가, 사망하면 한 단계 아래로.
- **시간제한 비경**: 지도 이름의 `[비경]`을 확인하면 지도 이동·자리 회피·퀘스트·영기·구매 등 부가 동작을 잠그고 게임의 일반 자동사냥(T)만 유지한다. 시간 종료 후 같은 일반 지도명이 두 화면에서 확인되면 앵벌 사냥터 선택과 이동을 자동으로 시작한다.
- **수집·보상 자동화**: 사용자 요청으로 끔. 프로필을 불러와도 켜지지 않는다.
- **보물찾기 안내**: 추천 → 보물찾기에서 현재 전투력으로 조사 가능한 첫 미완료 지역, 번호 지도와 등급별 수량을 확인한다. 찾은 번호는 직접 체크하며 `treasure_progress.json`에 저장된다. 지도 이동·조사·개봉은 자동화하지 않는다.
- **보스 프리셋** (bot2/preset.py): 보스 체력바가 3초 보이면 도술 프리셋 2(보스), 보스가 60초 안 보이면 1(일반).
- **HP**: 평소 물약은 게임 자동 물약에 맡긴다. 헬퍼는 휴식·자리 회피 중 Ctrl+1로 회복한다. 물약 50개 미만 자동 구매는 하루 1회다.
  - 위험 시 길라잡이 무료 순간이동을 우선 시도하고, 실패하면 기존 무료 걸어가기를 사용한다. 순간이동 후에는 위험한 원래 자리로 돌아가지 않는다.
  - 시작·재개 직후 같은 몬스터가 허용 전투력 비율을 넘는지 두 프레임에서 확인한다. 무료 순간이동에 실패하면 일시정지한다. 보스·이동 중·연습 모드는 제외한다.
- **도술 강화** (bot2/enhance.py, 기본 꺼짐): 재료가 충분할 때만 파멸·저격 계열 강화.
- **멈춤 감시**: 10분 동안 이동/전투/대화가 없으면 화면 저장 후 복구(지도 닫기 → ESC → 다른 퀘스트), 3번 실패하면 일시정지.
- **영기 수련**: 주기적으로 메뉴를 열어 빨간 점 노드를 수련.
- **사용자 양보**: 게임 창을 직접 조작하면 2분 쉬고 재개. 다른 창에서 하는 작업은 무시(`yield_only_game_input`).

## 자동화하지 않는 것
- 유료 상점(F8 영석 상점), 현금/영석 소모, '즉시 부활', '즉시 완료', '포기', 축지술(유료 이동)
- 문파 화면 (탈퇴 버튼이 있어 위험), 이벤트 창(이벤트마다 구조가 달라 받기 버튼을 일관되게 구분할 수 없음)

## 폰 알림 / 원격 제어
`config.yaml`의 `notify:` 또는 제어판 설정 → "알림 연결"에 입력.
- 텔레그램: @BotFather로 봇 생성 → 봇에게 아무 말 → `https://api.telegram.org/bot<토큰>/getUpdates`에서 chat id 확인
- 원격 명령: `/상태` `/화면` `/일시정지` `/재개` `/정지` (설정한 chat id에서 온 명령만 받음)
- 알림: 사망, 일시정지, 멈춤 복구, 시작, 매일 `report_hour`시 일일 리포트

## 단축키 / 안전장치
- `F12` 종료, `F11` 일시정지·재개 (마우스를 모서리로 옮겨도 멈추지 않는다 — 모서리에 닿으면 마우스를 화면 안쪽으로 옮기고 계속 진행)
- 게임 창이 맨 앞에 있을 때만 입력
- 10분 안에 3번 사망, 알 수 없는 화면 지속, 복구 실패 시 화면 저장 + 경고음 + 알림 + 일시정지
- 시작할 때 설정값·템플릿 점검, 하루 지난 브리지 이미지/일주일 지난 자동 저장 화면 정리, 로그는 5MB×5개 회전

## 배포판 검증과 출시 준비

빌드 환경은 Windows 64비트 / Python 3.14.6이다. `requirements-build.txt`에 검증한 의존성 버전을 고정했다.
`build_exe.bat`는 버전별 `dist\1.28.0\GameAutoPlay\GameAutoPlay.exe`를 만든다. 기존 배포 디렉터리는 보존한다.
배포판은 설정·로그·프로필·학습 숫자를 `%LOCALAPPDATA%\DokkaebiHelper`에 보관한다.
업데이트는 정적 인식 파일을 갱신하면서 기존 설정·사냥터 DB·학습 숫자를 유지한다.
이는 [PyInstaller의 번들 리소스 경로](https://pyinstaller.org/en/stable/runtime-information.html)와 영구 데이터 경로를 구분한 설계다.
종료는 작업 완료 신호를 받은 뒤 스레드를 정리한다. [Qt의 스레드 수명 지침](https://doc.qt.io/qt-6/qthread.html)을 적용했다.

```powershell
.\.venv\Scripts\python.exe gui.py --self-check --report screenshots\environment.json
.\.venv\Scripts\python.exe -m tools.package_verify
```

`package_verify`는 별도 `build\package-smoke-*` 데이터로 EXE 실행, 중복 실행 차단, 설정 왕복 저장,
자가 점검, 업데이트 후 설정·확장 키·학습 숫자 보존을 검사한다. 게임 입력은 보내지 않는다.
결과는 `build\package-verification.json`에 기록한다. EXE 검증은 관리자 권한 환경에서 실행한다.

v1.28은 상용화를 위한 배포 후보다. 우선순위는 실제 결함이 있던 데이터 보존·입력 중단·오류 복구·지원 진단으로 정했다.
외부 출시 전에는 다른 PC와 해상도/DPI에서의 검증, 장시간 연속 실행, 설치·업데이트·롤백 경험,
배포 서명과 의존성 고지 검토가 남아 있다. 짧은 로컬 검증으로 장시간 안정성을 보장하지 않는다.
